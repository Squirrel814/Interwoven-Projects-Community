# Interwoven Library Standards

**Part of the central governance in [GOVERNANCE.md](../GOVERNANCE.md)**. All `Interwoven-[Subject]-Library` repositories (e.g. Interwoven-Security-Library) must follow these standards.

## Core Requirements
- **Free Core**: All handbooks, checklists, tools, templates, infographics, and walkthroughs remain permanently free and open-source.
- **Attribution**: Follow [ATTRIBUTION.md](../ATTRIBUTION.md) and [docs/attribution-guidelines.md](../docs/attribution-guidelines.md). Any paid derivative (workshop, book) must credit all listed contributors.
- **Structure** (preferred layout):
  - `README.md` — orientation, citation examples, link to free materials.
  - `handbooks/`, `checklists/`, `tools/`, `templates/v1/`, `infographics/`, `web/` (hub).
  - Physical/cyber or subject-specific sections via clear subdirs or tags.
  - `CONTRIBUTORS.md` or link to project attribution.
- **Citation Standard**: Use `[Subject-Library/handbooks/Example.md §3](https://github.com/Interwoven-Projects/Subject-Library/blob/main/handbooks/Example.md#section-3)` so Education courses can reference cleanly.
- **Review Gates**: All PRs require attribution update, link validation, and alignment with ethics (Damian Echo patterns). Teaching approval is a separate process (see GOVERNANCE.md).
- **Templates**: Use templates from this Community repo's `standards/` or `templates/`.

**Teaching/Monetization**: Requires formal approval via "Teaching Approval Request" issue in this Community repo (even for major contributors). Must commit to free core materials and full credit.

See [GOVERNANCE.md](../GOVERNANCE.md) for qualification process, financial gain rules, and public draft status.

*Maintained in Interwoven-Projects-Community. PRs welcome for improvements.*
