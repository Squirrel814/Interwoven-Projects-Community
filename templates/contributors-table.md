# Contributors Table Template

Copy this into `ATTRIBUTION.md`, `CONTRIBUTORS.md`, or your project README for full transparency (including optional AI/tool-assisted work column per GOVERNANCE.md and CODE_OF_CONDUCT.md AI Transparency section).

```markdown
## Contributors & Credit

| Name / Handle          | Primary Role(s)              | Contributions                                      | X / Contact          | Email                     | AI Agent and/or Model |
|------------------------|------------------------------|----------------------------------------------------|----------------------|---------------------------|-----------------------|
| [Your Name]            | [Role]                       | [List contributions]                               | [@handle]            | [email]                   | [Model or 'none' / 'undisclosed'] |
| ...                    | ...                          | ...                                                | ...                  | ...                       | ...                   |
```

**Notes**:
- Human direction, curation, verification, and final responsibility are primary. Note this in the Contributions column when AI was used (e.g. "Grok assisted with initial drafting under human direction").
- Add rows for all meaningful contributors (including small but important work).
- Update this table whenever new contributions are logged via the Contribution Update issue template.
- Link to [GOVERNANCE.md](../GOVERNANCE.md) and [docs/attribution-guidelines.md](../docs/attribution-guidelines.md) in your project README.

This template supports the community's transparency goals and makes attribution easy to maintain.
